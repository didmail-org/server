# Historical Worker dependency evidence

Independent Workers deployment has been retired. This document and the
[retained CSV](worker-dependency-inventory.csv) describe the former compiler
inventory; they do not document a supported runtime or the current native package.

The original Worker inventory recorded 151 installed package instances. Its
[license collection](../third_party_licenses/worker-bundle-licenses.txt) preserves
original and recovered grants/notices, including protocol nested notices. Keep
that provenance: some of the same dependencies are present in the native asset.
Historical compiler counts and missing-text conclusions must not be carried over
without checking current bytes.

For current commands, hashes, package versions and unresolved release gates use
the [native Blocklet inventory](blocklet-dependency-inventory.md) and
[distribution audit](distribution-license-audit.md). Current audit reconstruction
has no dependency on `.worker/` or ignored `artifacts/ui-metafiles.json`.
