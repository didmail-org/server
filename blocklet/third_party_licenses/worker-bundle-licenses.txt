HPKE compatibility test data (source repository only)
========================================================================

The JSON fixture in docs/protocol/dmp-1/fixtures/hpke-rfc9180.json
selects public vector values and records from the CFRG HPKE test vectors.
The upstream file at the RFC 9180 reference and the earlier Cisco go-hpke
file at the revision below have identical Git blob SHA-1
514dd8bbcc4339f99ad9cf527007523f94668582. Every selected scalar value and
record in this fixture was checked against that file. The Cisco repository
at that revision includes the BSD 2-Clause License reproduced below and
identifies test-vectors.json as generated by its test-vector generator.

Cisco source and license (2021-05-24):
https://github.com/cisco/go-hpke/blob/13744bccfbe21a43be887884a7fc57c6642c6853/test-vectors.json
https://github.com/cisco/go-hpke/blob/13744bccfbe21a43be887884a7fc57c6642c6853/LICENSE
CFRG reference (same source blob, later on 2021-05-24):
https://github.com/cfrg/draft-irtf-cfrg-hpke/blob/5f503c564da00b0687b3de75f1dfbdfc4079ad31/test-vectors.json

The CFRG repository also describes its material as IETF contributions.
RFC 9180 is an IRTF-stream document; this notice preserves the license in
the verified Cisco source and does not purport to relicense the RFC itself.
This test fixture is excluded from the SDK npm package file list.
